# Integration logos

SVG marks from [Simple Icons](https://github.com/simple-icons/simple-icons), bundled locally and filled with the color specified by its metadata. The upstream CC0 license is included in LICENSE.md.

Brand sources:

- Firebase: https://firebase.google.com/brand-guidelines
- Stripe: https://stripe.com/newsroom/information
- Supabase: https://github.com/supabase/supabase/blob/4031a7549f5d46da7bc79c01d56be4177dc7c114/packages/common/assets/images/supabase-logo-wordmark--light.svg
- Sentry: https://sentry.io/branding/
- GitHub Actions: https://github.com/features/actions
- PostHog: https://posthog.com/handbook/company/brand-assets
- Better Stack: https://betterstack.com
- Vercel: https://vercel.com/geist/brands

Signed webhooks use the existing Lucide Webhook icon.
